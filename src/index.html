Quickstart Guide

Learn how to authenticate your client, initialize the SDK, and send your first API request in under 5 minutes.

Prerequisite: You need an active API key from the developer portal. Make sure you set the DOC_API_KEY environment variable before running scripts.

1. Install the SDK

Install the official SDK package using your preferred package manager:

Terminal 
npm install @doccore/sdk-node --save

2. Initialize Client & Fetch Data

Construct the client instance and query the cluster telemetry endpoint:

index.js 
import { DocClient } from '@doccore/sdk-node';

const client = new DocClient({
  apiKey: process.env.DOC_API_KEY,
  region: 'ap-singapore'
});

async function getClusterStatus() {
  const response = await client.telemetry.getOverview();
  console.log(response.data);
}

getClusterStatus();

Request Parameters

Supported configuration attributes passed to the initialization object:

Parameter Type Required Description
apiKey string Yes Your secret bearer key starting with sk_live_
region string No Target data center region. Default is ap-singapore
timeoutMs number No Maximum request timeout in milliseconds. Default: 5000ms.
